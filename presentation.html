LE PROJET

CONCEPT
Application web de commande de cocktails sur thème Burnout / Racing PS2. Le client commande depuis son téléphone, le barmaker prépare et fait avancer chaque étape en temps réel.
RÔLE CLIENT
Consulter la carte · Composer un panier · Lancer une commande · Suivre la préparation (PitTracker)
RÔLE BARMAKER
Voir toutes les commandes · Avancer les étapes · Administrer la carte · Gérer l'équipe
THÈME GRAPHIQUE
Univers racing : Pit Lane, Garage Cart, PitTracker, Takedown Signature — immersion totale dans l'ambiance du bar.

PROTECTION DES DONNÉES

MOTS DE PASSE — BCRYPT
Les mots de passe sont hachés avec BCrypt avant stockage. Impossible de retrouver le mot de passe original depuis la base.

ENDPOINTS — INTERCEPTEUR SPRING MVC
Au login → token UUID généré, stocké en mémoire.
Chaque requête barmaker envoie le header X-Auth-Token.
L'intercepteur vérifie le token et le rôle avant d'atteindre le contrôleur.

ZOOM TEST

UN TEST DÉCORTIQUÉ

// CommandeServiceTest.java
@Test
void avancerLigne_allTerminee_commandeTerminee() {
  // 1. Prépare les données
  Commande commande = Commande.builder()
    .id(1L).statut(EN_COURS).build();
  LigneCommande ligne = LigneCommande.builder()
    .statut(DRESSAGE).build();
  commande.getLignes().add(ligne);

  // 2. Configure les mocks
  when(commandeRepository.findById(1L))
    .thenReturn(Optional.of(commande));
  when(ligneRepository.existsByCommandeIdAndStatutNot(...))
    .thenReturn(false); // plus de ligne active

  // 3. Exécute
  commandeService.avancerLigne(1L, 1L);

  // 4. Vérifie
  assertThat(commande.getStatut())
    .isEqualTo(TERMINEE);
}
① ARRANGE
On construit les objets dont le service a besoin : une commande EN_COURS avec une ligne en DRESSAGE (dernière étape avant TERMINÉE).
② MOCK
Le repository est simulé — il retourne nos objets sans toucher à aucune base de données. Le test est isolé et ultra-rapide.
③ ACT
On appelle la vraie méthode du service. C'est elle qui contient la logique métier à valider.
④ ASSERT — LA RÈGLE MÉTIER
Quand toutes les lignes sont TERMINÉES, la commande passe automatiquement à TERMINÉE. C'est la règle testée.
